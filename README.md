# 🌐 Personal Portfolio Website

Selamat datang di repository website portofolio pribadi saya! Website ini dirancang untuk menampilkan profil profesional, keahlian, proyek-proyek yang telah saya kerjakan, serta pengalaman di bidang pengembangan web.

---

## 🎨 Tampilan & Fitur Utama

- **Responsive Design:** Tampilan optimal di berbagai perangkat (*Mobile, Tablet, Desktop*).
- **Modern & Clean UI/UX:** Didesain dengan tata letak yang rapi, transisi halus, dan hierarki visual yang jelas.
- **Section Profil & Skill:** Menampilkan daftar keahlian (*technical skills*) dan teknologi yang dikuasai.
- **Galeri Proyek (Showcase):** Katalog proyek yang dilengkapi dengan deskripsi, *tech stack*, dan link *Live Demo*.
- **Form Kontak:** Memudahkan pengunjung atau klien untuk menghubungi saya secara langsung.
